# Безымянный мессенджер

Это асинхронный бэкенд для мессенджера, находящийся в разработке.

## Описание
Проект представляет собой серверную часть мессенджера с использованием современных асинхронных технологий. Весь код написан с использованием асинхронных паттернов, включая работу с базой данных через асинхронные сессии SQLAlchemy.

## Реализованные функциональные фичи

### Управление пользователями
- **Регистрация пользователя** (`POST /users/sign_up`) — создание нового пользователя с хэшированием пароля
- **Авторизация** (`POST /users/login`) — вход в систему с получением JWT токена
- **Получение информации о пользователе** (`GET /users/{user_uuid}`) — получение данных пользователя по UUID
- **Список пользователей** (`GET /users/list`) — получение списка пользователей с поддержкой поиска по email и username
- **Добавление контактов** (`POST /users/{contact_uuid}/contact`) — добавление другого пользователя в контакты
- **Валидация данных** — проверка email, пароля, уникальности email и username

### Аутентификация и авторизация
- JWT токены с настраиваемым временем жизни
- Хэширование паролей с использованием bcrypt
- Управление сессиями пользователей (создание при логине)
- Защита эндпоинтов с помощью токенов

### Модели данных
- **Пользователь (User)** — uuid, email, username, password, created_at, updated_at
- **Сессия (Session)** — uuid, user_uuid, expires_at, device_info
- **Контакт (Contact)** — uuid, owner_id, contact_id (связь многие-ко-многим между пользователями)

### Архитектурные особенности
- Generic контроллеры с использованием Python 3.12 синтаксиса (`class Controller[T]`)
- Dependency Injection через FastAPI Depends с использованием `Annotated`
- Строгая типизация с помощью mypy
- Полное покрытие тестами (unit и интеграционные)
- Использование асинхронных драйверов для PostgreSQL (asyncpg)
- Миграции базы данных через Alembic

## Технологии
- Python 3.12
- FastAPI (асинхронный веб-фреймворк)
- SQLAlchemy 2.0 с асинхронным драйвером asyncpg
- Pydantic v2 для валидации данных
- JWT (python-jose) для аутентификации
- bcrypt для хэширования паролей
- Poetry для управления зависимостями
- pytest для тестирования
- ruff для линтинга и форматирования
- mypy для статической типизации
- Alembic для миграций базы данных

## Запуск

### Требования
- Python 3.12+
- PostgreSQL 13+
- Poetry

### Установка
1. Установите Poetry, если не установлен: `pip install poetry`
2. Установите зависимости: `poetry install`
3. Настройте переменные окружения (см. `.env.example`)
4. Примените миграции: `poetry run alembic upgrade head`
5. Запустите сервер: `poetry run uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload`

Сервер будет доступен по адресу: http://localhost:8000

### Документация API
После запуска сервера доступна автоматически сгенерированная документация:
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

### Проверка работоспособности
Эндпоинт `/system/ping` возвращает `pong`:
```bash
curl http://localhost:8000/system/ping
```

## Тестирование
Запуск всех тестов:
```bash
poetry run pytest
```

Запуск тестов с параллельным выполнением:
```bash
poetry run pytest -n auto
```

Запуск тестов с покрытием:
```bash
poetry run pytest --cov=src --cov-report=html
```

Проверка типов:
```bash
poetry run mypy src
```

Проверка кодстайла и форматирование:
```bash
poetry run ruff check . --fix
poetry run ruff format
```
